# ps5/native-app — native-title (PPSA) link + package tail

Vendored, unmodified, from EVO-PLAYER-PS5 `tools/native-app/`
(https://github.com/sainsaji/EVO-PLAYER-PS5), which itself vendors
`blackbearreloaded/ps5-native-app-boilerplate` (`a15ab71`) by way of
ProsperoLight. GPL-3.0-or-later; all upstream SPDX/copyright headers kept.
See EVO's tools/native-app/README.md for what each piece does.

Used by `ps5/package_app.sh`. `runtime/libc.prx` is the clean-room runtime
shim generated by `libc_builder.cpp` from `runtime/*.txt` (no Sony code);
its signed sha256 is pinned in `runtime/libc.prx.sha256`.
